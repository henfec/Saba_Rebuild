# Cafe Saba Rebuild - Prototype (UED100 Assessment 2)

Responsive HTML, CSS and JavaScript prototype that redesigns the Cafe Saba website
(https://www.cafesaba.net). All dishes, prices, hours, phone numbers and captions are sample content
written for this prototype. No text or photos are copied from the real site.

## Run it
Open `index.html` in a browser. No build step and no libraries.

## Files
- `index.html`, `menu.html`, `bookings.html`, `contact.html`: the four pages
- `css/base.css` (tokens, typography), `css/layout.css` (nav, grid, breakpoints), `css/components.css`
- `js/nav.js` (mobile menu), `js/menu-filter.js` (menu filter), `js/form-validate.js`, `js/slideshow.js`
- `img/` compressed WebP images (add your own or free-licence photos, with credits below)
- `wireframes/` Figma exports

## Findings answered (from the Part A analysis)
F2 headings, F3 alt text, F5 slideshow pause, F6 one booking route, F7 hours as text, F8 static menu,
F9 accessible form, F11 contrast, F12 meta description.
